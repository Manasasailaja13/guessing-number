# 🎯 Number Guessing Game (Python)

## 📌 Description
This is a simple Number Guessing Game developed in Python. The game is played by two players.

- Player 1 enters a secret number.
- Player 2 tries to guess the secret number within the given number of attempts.
- The game provides hints such as **Too Low** or **Too High** after each incorrect guess.
- The secret number is hidden using Python's `getpass` module. :contentReference[oaicite:0]{index=0}

## ✨ Features
- Three difficulty levels:
  - Easy (1–10, 5 attempts)
  - Medium (1–50, 7 attempts)
  - Hard (1–100, 10 attempts) :contentReference[oaicite:1]{index=1}
- Hidden secret number using `getpass`
- Hint messages (Too High / Too Low)
- Limited number of attempts
- Winning and Game Over messages

## 🛠️ Technologies Used

- `getpass` module

## ▶️ How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the program:

```bash
python guessing-number.py
```

## 🎮 How to Play
1. Choose a difficulty level.
2. Player 1 enters the secret number.
3. The screen clears to hide the number.
4. Player 2 guesses the number.
5. The game gives hints until the correct number is guessed or all attempts are used. :contentReference[oaicite:2]{index=2}
